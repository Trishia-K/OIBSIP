# Pzazrio Naturals Landing Page

This is a responsive landing page I built for **Pzazrio Naturals** which is a Ugandan brand that creates 100% natural, fungal acne-safe skincare and hair growth products.

I created this project as part of my **OIB-SIP Web Development Internship (Level 1 - Task 1: Landing Page)** to practice my HTML and CSS skills.

---

## Project Overview
The main goal was to build a visually appealing static landing page using only **HTML5 and CSS3**. 

I chose Pzazrio Naturals because I wanted to design something for an authentic local African brand. The site has an earthy, natural color palette (beige, sage green, deep olive and warm brown) and real product photos.

---

## Features Built
- **Sticky Navigation Bar:** Keeps links accessible at the top while scrolling.
- **Hero Section:** This section has the bold headline, a pure African roots badge, a background overlay image, and buttons to expore more products or contact on whatsapp.
- **What Makes Us Special:** This is a card layout that highlights that the products are fungal acne-safe and 100% natural Ugandan products.
- **Featured Products:** Displays top 3 bestsellers with images and prices then a button linking directly to their Instagram to view more.
- **Custom Advice CTA:** Interactive callout section prompting users to reach out on WhatsApp for skin and hair recommendations.
- **Footer Section:** Includes contact details, location, and social media links (Instagram, TikTok, X).


---

## Tech Stack
- **HTML5** (Semantic elements)
- **CSS3** (Flexbox, CSS Grid, custom variables, image overlays, smooth scrolling)
- **Google Fonts** (*Cinzel* for headers & *Plus Jakarta Sans* for body text)
